# 交易物种起源 · 代码与运行说明

## 目录

| 目录 | 内容 |
|---|---|
| `h5/` | 线上主作品。React 18 + TypeScript + Vite 5，状态用 zustand，动画用 framer-motion，3D 手办用 model-viewer |
| `h5/src/game/` | 游戏规则与画像引擎：`engine.ts`（画像、推荐、终局分）、`cards.ts`（规则牌、任务卡）、`meta.ts`（物种、理由、AI 对手）、`demo.ts`（评委演示台的模拟玩家）、`handoff.ts`（Qube 一句话）、`adaptive.ts`（快速版的下一场推荐）、`glossary.ts`（术语表） |
| `h5/src/screens/`、`h5/src/pages/` | 各页面：名场面六步、棋盘、驿站、终局、二维码落地页、评委演示台 |
| `content/` | 内容的唯一来源：`scenes.json`（名场面、证据、收益表）、`decks.json`（牌堆、物种、任务、资源）、`rules_eval.json`（规则牌放回名场面的结果）、`qr.json`（二维码） |
| `data/` | 行情抓取：`fetch_market.py` 从 Panda Data（或公开接口）取日线，存到 `data/series/` |
| `print/` | 桌游印刷件：HTML 排版转 PDF，3 mm 出血、拼版、真二维码 |
| `3d/` | 物种手办和令牌的 3D 打印文件，说明见 `3d/3D打印说明.md` |
| `qa/` | 自动通关脚本和落地页巡检 |

## 运行 H5

需要 Node 22 和 pnpm。

```bash
cd h5
pnpm install
pnpm dev            # http://localhost:5178/ts/
```

构建静态文件（部署路径是 `/ts/`，产物在 `h5/dist/`，任何静态服务器都能托管）：

```bash
cd h5
python3.11 scripts/subset_fonts.py   # 按正文实际用字生成中文字体子集，改过文案后要重跑
pnpm build
npx vite preview --port 5179         # 本地预览 http://localhost:5179/ts/
```

H5 是纯前端，不需要后端和数据库。游戏记录只存在浏览器本地。

## 内容和数据管线

行情、证据和收益表都是离线算好再打进 H5 的。改内容的顺序：

```bash
python3.11 data/fetch_market.py --source panda   # 取行情，存到 data/series/
python3.11 content/build_scenes.py               # 由行情计算名场面里的数字和收益表
python3.11 content/build_rules_eval.py           # 规则牌放回各名场面的结果
python3.11 content/check_decks.py                # 校验牌堆
python3.11 h5/scripts/prepare_content.py         # 把 content/ 复制进 h5/src/data/
```

- Panda Data SDK 是 `panda_data==0.0.12`，需要 Python 3.10 以上。
- 账号写在仓库外的本地配置文件里（`PANDA_USERNAME`、`PANDA_PASSWORD` 两行），脚本只在进程内使用，不打印、不落盘。仓库和提交材料里不含任何账号或密钥。
- 没有 Panda Data 账号时，`python3.11 data/fetch_market.py` 不带参数会改用公开接口；`--probe` 只测试登录和各接口权限。
- 原始响应缓存在 `data/raw/`，重跑不再请求网络。每个序列都带 `source` 字段，页面按它标注数据来源。

## 自动测试

需要 Python 3.11 和 Playwright（Chromium）。先启动本地预览，再跑：

```bash
python3.11 qa/e2e_play.py --base http://127.0.0.1:5179/ts/ --run Q   # 快速版，连玩两场
python3.11 qa/e2e_play.py --base http://127.0.0.1:5179/ts/ --run A   # 完整四季，三种不同打法 A / B / C
python3.11 qa/pages_check.py --base http://127.0.0.1:5179/ts/        # 巡检全部二维码落地页
```

截图和每一步的记录写在 `qa/e2e/<路径>/`，可以用 `--out` 指定别的目录。

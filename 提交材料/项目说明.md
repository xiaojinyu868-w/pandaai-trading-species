## 一、故事：不是韭菜，那你是哪一种？

1720 年，南海泡沫。相传牛顿先赚了一笔，又在更高的价格买回去，最后亏掉约 2 万英镑。三百年来，同样的名场面一次次重演：2015 年人人借钱买股票，2020 年美股十天熔断四次，2024 年国庆前全民排队开户。

每一次，站在同一段行情前面的人，做法都不一样：有人追，有人等，有人听消息，有人先去翻数据。**差别不在于谁赚了，而在于他怎么做决定。**

《交易物种起源》把玩家放回这些真实的历史时刻。名字和日期藏起来，他只能看到当时的人能看到的东西。他先看什么证据、为什么这么选、说好的计划有没有照做、恐慌的时候做了什么，这些都会留下线索。四季走完，他会知道自己像哪种“交易物种”（猎豹、大象、狐狸、猫头鹰、狐獴、变色龙，还有隐藏的海狸）、判断依据是什么、哪里还不确定，以及**下一步在 PandaAI 上可以做什么**。

这正好对应赛题要连起来的四件事：

| 赛题 | 我们怎么做 |
|---|---|
| 了解用户 | 不问问卷，让他在真实行情里做决定 |
| 形成画像 | 每个判断都指向一个具体动作，不确定的地方直接写出来 |
| 推荐资源 | 按他的做法，推荐 PandaAI 的工具和任务，并说明原因 |
| 开始行动 | 把他的习惯写成一句可以回测的规则，复制进 Qube 就能开始 |

我们做的是**一整套东西**：一盒能单独玩的桌游，一个能单独玩的 H5，两边是同一个游戏，用同样的名场面、同样的行情、同样的规则。一个人在手机上，几个人在桌上，最后都交给同一套方法来判断。

## 二、适合谁，在什么时候用

| 形态 | 谁 | 什么时候 | 时长 |
|---|---|---|---|
| 手机 · 3 分钟版 | 第一次来 PandaAI 的新用户，或者被朋友转发的人 | 注册后的第一站、社群里转发、展位扫码 | 约 3 分钟 |
| 手机 · 完整四季 | 想知道自己是哪种的人；略懂投资的人和小白 | 一个人、有十分钟 | 约 10 分钟 |
| 桌游 | 投教课堂、平台的线下用户活动、展会、朋友聚会 | 几个人坐在一起 | 1–5 人，60–90 分钟；展台快玩 15 分钟 |

目标用户是 PandaAI 的种子用户：略懂投资的人和完全的小白。所以全程不用术语打底：一屏只讲一两件事，手机上只有一个手势，即**按住 = 拿着，松手 = 卖出**。

## 三、线下：一盒桌游

### 怎么玩

一张方形环路棋盘，每条边是一季（春入场、夏狂热、秋松动、冬危机）。每季掷骰子走到小格（补给站、机会、研究所、数据港口、冷静亭），再推开名场面之门：

1. **盲入场**：翻开场景牌，只有一张走势图和“当时的处境”，没有名字和日期。
2. **查证据**：花研究点看量价、数据、消息、锦囊四张证据牌。研究点不够看全，先看哪张也是线索。
3. **填委托单**：每季撕一张季节色的委托单，勾选项（A–D，旁边印着几份仓位）、勾理由（量价 / 数据 / 消息 / 跟别人 / 直觉 / 看不懂，或写规则牌），再勾“跌了怎么办”（跌了就走 / 跌了就加 / 不定计划）。对折扣下，倒数三二一一起翻开。
4. **招牌机制**：每场一个，把当时的处境做成手感。春季是开户排队条，排在后面的人看得见队有多长。夏季是卖出窗口和跌停锁，名额只有一半，没挤上的人下一段照样跌。秋季是抱团圈，同时离开的人越多，每个人亏得越多。冬季是熔断沙漏，全桌 30 秒不许说话、不许碰牌。
5. **揭幕**：扫揭幕牌的码，看真实走势一根根长出来，按真实日线结算。
6. **驿站**：按这一季的做法发一枚物种币。

单人可以选两张 AI 物种牌当对手（入门：猎豹 + 狐獴；进阶：猫头鹰 + 大象）。每张 AI 牌背面写着它每一场选什么、凭什么。

### 桌上为什么能认识一个人

| 桌上的动作 | 读出什么 |
|---|---|
| 研究点花在哪张证据上、先翻哪张 | 研究习惯，看重哪类信息 |
| 委托单上的理由 | 决策依据。**理由比选项重要**：同样选“等”，有人在等证据，有人是看不懂 |
| 委托单上的计划，以及招牌机制里有没有照做 | 压力下是否说到做到 |
| 排队条上看见别人排队后的选择、抢不抢卖出窗口 | 受不受人群影响 |
| 申报“认出来了”并写对事件名 | 金融史知识；认出来的那一场，钱按两只 AI 的平均记，物种币只算半枚，不把“知道结局”当成“判断准” |

终局把两本账分开：**资金账**记结果，**方法账**（方法星）记你怎么做的决定，终局分把两本账加在一起。物种只表示偏好；能力用徽章单独记（证据控、说到做到、金融史达人、数据手、规则派、看懂风险）。四枚币的多少决定把握（很确定 / 比较确定 / 初步），并列时两张物种牌并排放，写“待确认”。档案卡背面有一棵决策树，从上往下第一个符合的就是你的任务牌，指向 PandaAI 和 QuantSkills 的真实工具。

### 为什么一定要有一盒桌游

- **面对面说出“为什么”**。理由是画像里最有价值的线索，几个人坐在一起翻委托单、互相追问，比一个人点按钮说得更多。
- **群体行为只有在人群里才真实**。排队、抢出口、熔断时的沉默，都要有别人在场才有那个味道。
- **投教场景本来就在线下**。课堂、用户活动、展会都需要一个能摊开、能盖章、能拍照的东西。我们还做了七个物种的 3D 打印手办。
- **它不依赖网络和账号**，能单独玩完一整局。

## 四、线上：一部手机

### 一局怎么走

和桌游同一个骨架：

1. 序章；
2. 自评（凭感觉选一个最像自己的物种）并挑两位 AI 对手；
3. 棋盘：掷骰子、踩格子；
4. 名场面；
5. 驿站领物种币；
6. 四季之后进终局。

**名场面是四个小动作**，每屏只有一个大按钮，或者那个手势：

| 步骤 | 玩家做什么 | 对应桌上的 |
|---|---|---|
| 盲盒 | 一张整屏海报和一句处境。可以申报“我认出来了” | 场景牌、认出令牌 |
| 线索 | 四张扣着的证据卡，翻一张花 1 研究点；再一键选“买了以后跌 5%，你会？走 / 加 / 到时再说” | 证据牌、委托单 |
| 出手 | 真实行情一格一格长出来，按住就是拿着，松手就是卖出。按钮上只写当下的状态（“按住 买入”或“拿着”），“松手 = 卖掉”写在按钮下面，不被手指挡住；开局有货的场次要按住才开盘，空仓的场次自动开盘；不到 0.3 秒的轻点不算交易。说好的计划画成一条虚线，真跌到那里会提醒你。两位 AI 对手按桌上自己那张牌的打法，在同一张图上买卖 | 委托单的选项、招牌机制、AI 物种牌 |
| 揭幕 | “原来是 2015 年杠杆牛”：完整走势、你的买卖点、印章（如“节后逃顶”“被强平”“第一个松手”）、盈亏、说到做到了没有、AI 的一句旁白；入账后看资金榜和方法星 | 揭幕牌、资金账、方法账 |

每一场的小游戏都带着这一场的招牌机制，和桌上同名同义：

- **924**：国庆长假休市七天，节前不上车，节后就只能排队。
- **2015**：有人要借钱给你，借得越多亏得越多；跌破强平线会被替你卖掉；跌停那几天想卖也卖不出去。
- **茅台**：抱团圈里的人一个一个离开。
- **2020 熔断**：十天里四次暂停交易，谁都动不了。

**终局**：AI 读四季的操作，结果一页讲一件事，点一下翻页：

1. 你的物种和一个称号；
2. AI 读你：凭什么这么判断，三个最能说明你的瞬间；
3. 模拟盘 ≠ 实盘；
4. PandaAI 下一步：把你的习惯写成一句可以回测的规则，一键复制并打开 Qube；
5. 带到桌上：开局把你的物种卡摆在面前，看看桌上的你还是不是它。

最后可以打开“完整画像档案”，里面是每条判断的依据、徽章、推荐任务卡和当场能做的任务。

### 手机比纸多读到什么

纸上只能记一个选项；手机能记下**整段行情里的每一次手指动作**：

| 行为 | 读出什么 |
|---|---|
| 什么时候第一次买、之前一周涨跌多少 | 追涨还是逢低 |
| 拿着的时候最深扛过多少 | 对回撤的承受，只标“游戏内表现” |
| 一共买卖几次 | 节奏快慢 |
| 借不借钱、借几倍 | 风险姿态 |
| 抱团圈走了几个人你才走 | 跟不跟人群 |
| 熔断后马上卖，还是恐慌里买 | 逆境反应 |
| 说好的计划，真跌到时照没照做 | 说到做到 |
| 每张证据看了多久 | 真正看重哪类信息 |

### AI 在哪里，做什么，不做什么

- **每场一句旁白**（约 0.7 秒），点出这一手最有意思的地方。
- **终局判断**（约 1.3–2.8 秒）。AI 拿到的是各场操作的中文摘要（由本地规则从操作里写出）、本地规则算出的各物种得分、玩家的开局自评。它可以不同意本地得分，但物种只能从六个里选，必须引用具体动作，只有一场时要说明是初步判断。我们明确告诉它：**盈亏只是结果，不能用来判断能力或物种**。
- **模型**：DeepSeek（`deepseek-v4.1-flash`），失败换 Qwen（`qwen3.8-flash`），再失败就用本地规则出完整结果，界面照常走。
- **安全**：发给 AI 的只有游戏操作，没有任何个人信息。服务端有限流，密钥不进前端。AI 写的内容都标“AI 生成”。

## 五、线上线下：同一个游戏

### 同一套东西

名场面卡、证据、行情、选项、每份仓位的结算数字、招牌机制、AI 物种的打法，两边是同一份数据（`content/scenes.json`、`content/decks.json`）。线上没有改动任何印刷的规则和数字。

### 五个衔接点

| 衔接点 | 发生了什么 |
|---|---|
| **桌上扫码 → 手机** | 88 个二维码都是无意义的短码，扫之前看不出是哪一场，不剧透。证据牌背面在自己手机上私下看，揭幕牌看真实走势一根根长出来，熔断牌有 30 秒计时器，规则牌直达 Qube 对应模板，任务牌打开下一步资源 |
| **在手机上玩这一场** | 扫到名场面的盲测码，页面上有“在手机上玩这一场”：直接用手机玩桌上这张卡、这段行情 |
| **手机 → 带到桌上** | 手机终局最后一页：开局把你的物种卡摆在面前，在桌上再玩一次 |
| **档案卡 → 手机** | 桌游玩完，扫终局档案卡上的码，把四季的委托单录进手机，用同一套规则生成完整画像和推荐 |
| **短码可以改指向** | 印好的卡不用重印，服务端改一张映射表（`q-map.json`）就能换内容 |

### 两边结合，对画像有什么用

赛题说“一次选择也不足以定义一个人”。我们的办法是**在不同场景下多看几次同一个人**：

- **开局自评**：他以为的自己；
- **手机上**：一个人、没人看着时的做法；
- **桌上**：有人排队、有人抢出口时的做法；
- **终局两道现实题**：现实里上一次大跌时做了什么，上一次买入的主要原因。

这几份结果并排放。对不上的地方本身就是信息，比如“你选的是大象，做法更像猎豹”“没有真钱时人往往更敢”。**目前是并排对照，还没有把桌上和手机上的记录自动合并成一份画像。**

## 六、画像：观察到什么，判断什么，哪里不确定

**能力、偏好、习惯分开**。物种只表示偏好；能力用徽章单独记；“把握”是证据够不够，不是分数高低。

| 维度 | 类型 | 行为依据 |
|---|---|---|
| 证据使用 | 能力 / 习惯 | 翻了几类证据、先翻哪类、各看了多久；理由和看过的证据一致不一致 |
| 金融知识与历史 | 能力 | 认出来了并写对事件名；点开过哪些术语解释 |
| 量化与工具准备度 | 能力 | 数据港口里读懂 `panda_data` 代码的次数；用规则牌做决定并照做 |
| 决策依据 | 偏好 | 委托单理由；手机上看得最久的那类证据 |
| 风险姿态 | 偏好 | 仓位、借不借钱、扛过多深的回撤（只标“游戏内表现”） |
| 逆境反应 | 习惯 | 计划被触发后照没照做；跌停、抱团散场、熔断时的动作 |

**不确定的地方，写出来，不硬判**：

- 只玩一场时，置信度一律是“初步”，AI 也要说明这一点；快玩版的最后一个按钮是“继续完整四季”。
- 物种币并列时写“待确认”，两张物种牌并排放。
- 认出来了的那一场单独处理（见第三节），不把“知道结局”当成“判断准”。
- 自评和行为不一致，直接写出来。
- 风险类结论只算“游戏内表现”。“模拟盘 ≠ 实盘”那一页用玩家自己扛过的最深回撤举例：真钱亏损的痛感大约是同样盈利快乐的两倍（损失厌恶），所以换成真钱，这一下的感受接近两倍，页面写明是估算。

**收益不是能力**。两本账分开记；AI 判断时也被要求只看“怎么做的决定”。

## 七、推荐：为什么推荐，下一步是什么

| 推荐 | 依据 | 下一步 |
|---|---|---|
| **一句给 Qube 的回测请求** | AI 按他四季的操作，把习惯写成明确规则（买入条件、卖出条件、止损） | 一键复制并打开 PandaAI Qube，粘贴就能检验“我这个习惯在历史上有效吗” |
| **物种对应的 PandaAI 功能** | 物种 | 例：猎豹 → Qube 均线与动量模板；大象 → Qube「低 PB + 高 ROE」、A 股个股档案；狐狸 → B10 因子评估、因子大赛；猫头鹰 → 市场状态判断智能体；狐獴 → 证据核查任务、EVO 对抗复核 |
| **任务卡**（12 张：6 类 × 入门 / 进阶） | 决策树按行为选：理由多是“看不懂”→ 读图入门；有数据手徽章 → 数据自主探索；猫头鹰，或者有理由地观望 → 状态判断；理由多是“消息 / 跟别人”→ 证据核查；其他 → 假设检验。有能力徽章拿进阶版 | 每条推荐都写“因为……”，也写“暂时不推荐什么、为什么”；终局有一个约 1 分钟当场能做的任务，比如把一条规则放回他走过的名场面按真实日线回放，或者判断三条“流传的说法”的真假 |
| **再玩一场** | 快玩版只有一场 | 继续完整四季，让画像有更多证据 |

赛题举的例子“两位用户都选择继续观察，但原因不明”，我们在委托单上就区分了：有理由地等（等证据）走“状态判断”，因为“看不懂”而等走“读图入门”。

## 八、Panda Data 怎么用

**数据决定了情境，也决定了结算。** 名场面的走势、证据里的数字、每份仓位的盈亏，都从真实日线算出来。

| 用在哪 | 接口 |
|---|---|
| 924、2015 的行情和结算（上证指数） | `get_index_daily` |
| 量化踩踏的行情（国证 2000），对比沪深 300 | `get_index_daily` |
| 茅台的行情和结算（前复权） | `get_stock_daily_pre` |
| 茅台 PE TTM、PB（数据证据） | `get_factor` |
| 上证指数 PE、PB（数据证据） | `get_index_indicator` |
| 2015 跌停和停牌家数、924 两市成交额（全市场逐只统计） | `get_stock_daily` |
| 2020 熔断的桌游结算（纳指 ETF 513100，不复权） | `get_fund_daily` |
| 原油宝的国内原油期货（上海原油 SC 各月合约） | `get_future_daily` |
| 棋盘上的数据港口：读一段 `panda_data` 调用代码并回答问题 | 代码展示 |

## 十一、接入 PandaAI 的潜力

- **用户与场景**：PandaAI 用户的差异在于已经会什么、习惯怎么研究、需要 AI 帮到什么程度。游戏读的正是这三件事：证据使用、决策依据、工具准备度。它可以放在注册后的第一站，也可以放在线下活动里。
- **画像结构化输出**：
  - 终局可以导出画像 JSON（`trading-species/profile@1`）：物种与把握、各维度的等级、依据、把握、待确认、推荐与理由、暂不推荐、查过的术语、玩过的场数。
  - AI 判断本身也是结构化的：物种、称号、依据、三个瞬间、实盘提醒、Qube 规则、自评对照。
  - **目前是格式示例，没有接入任何平台账号。**
- **推荐能落到产品里**：Qube 一句话现在靠复制粘贴交接，接入后可以带参数直接打开。之后用 Qube 回测、因子评估这些平台行为，继续修正画像里“待确认”的部分。
- **好维护、能扩展**：
  - 新的名场面走同一条数据管线：Panda Data 取数 → 自动算出证据数字和结算表 → 打进 H5 和印刷件。
  - 二维码是短码，可以改指向。
  - AI 服务是一个独立的小服务，失败有本地兜底。

## 十三、隐私

- 不需要登录，不收集个人信息。游戏记录只存在玩家本机的浏览器里。
- 发给 AI 的只有游戏操作的摘要。
- 分享图只有物种和徽章，不含行为记录；现实题的答案只留在本机。扫码页面不记录任何信息。
- 演示材料不含个人信息和数据访问密钥。

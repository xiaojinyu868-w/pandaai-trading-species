# 交易物种起源 · 项目说明

> PandaAI 赛道 ·「寻找你的交易人格：用游戏认识用户」
> 投资者教育游戏，不构成投资建议。

## 体验入口

| 入口 | 地址 | 说明 |
|---|---|---|
| H5 主作品 | https://meetmind.online/ts/ | 手机直接打开，不用登录。首页“先玩一场 · 3 分钟”是快速版；“开始一局”是完整四季，约 15 分钟 |
| 评委演示台 | https://meetmind.online/ts/demo | 五位**模拟玩家**走同样的名场面。改任何一个选择，物种、画像和推荐当场重算 |
| 桌游 | 印刷文件与 3D 打印文件另附 | 同一套内容的实体版。卡牌、规则书和记录卡上共 88 个二维码，扫码接回线上 |

## 一句话

玩家回到真实的金融史时刻（名字和日期都藏起来），用当时能看到的信息做决定。游戏只看他**怎么做决定**：先看什么证据、为什么这么选、有没有计划、压力下是否照做。据此判断他像哪种“交易物种”，每条判断都附上依据和把握，最后给出一个当场就能做的下一步，并接到 PandaAI 的真实工具上。

## 怎么玩

1. **开局自评**：凭感觉选一个最像自己的物种（猎豹、大象、狐狸、猫头鹰、狐獴、变色龙；还有一种隐藏物种海狸）。
2. **名场面**：快速版选一场，完整版四季各一场。现在有六场：春 · 924 国庆全民开户、夏 · 2015 杠杆牛、秋 · 茅台抱团瓦解、冬 · 2020 美股熔断，进阶的秋 · 2024 量化踩踏和冬 · 原油宝。每场分六步：

   | 步骤 | 玩家做什么 | 画像记下什么 |
   |---|---|---|
   | 看情境 | 看盲测海报和决定日之前的走势 | 是否申报“认出来了” |
   | 查证据 | 用研究点打开量价、数据、消息或锦囊，通常看不全 | 看了哪些、先看哪份 |
   | 做决定 | 填委托单：怎么做、主要因为什么、跌 5% 怎么办 | 选项、理由、计划 |
   | 亮牌 | 和两只 AI 物种同时翻牌，听它们的理由 | — |
   | 快进 | 每场一个招牌机制：排队开户、跌停卖不出、抱团圈、熔断沙漏、量化出口、负油价 | 压力下是否照计划做 |
   | 揭幕 | 揭晓事件，按真实行情结算收益账和方法账 | — |

3. **驿站**：按这一场的做法发一枚物种币，并写出“为什么说你像它”。不同意可以答一道补测题，答案支持你就换币。
4. **终局**：物种（带把握）、“两个你”（自评和行为对照）、七个维度的画像、徽章、推荐、当场能做的任务，以及一句可以直接带去 PandaAI Qube 回测的话。

完整版还有四季环形棋盘：掷两颗骰子挑一个点数，沿路拿研究点、答机会题、拿规则牌、读 `panda_data` 代码。

## 对照评分标准

### 趣味性与体验设计（25）

- **盲测真实历史**：名字和日期藏起来，揭幕时才知道“原来是那一次”。
- **六个名场面各有一个专属快进玩法**，把当时的处境做成手感，比如 2015 年千股跌停时想卖也挤不出去，熔断时沙漏倒计时。
- **两只 AI 物种同场对局**，亮牌时各自说理由；最后按方法星和资金名次算终局分。
- **两本账**：收益账记赚了多少，方法账记想得怎么样，两本账视觉权重相同。
- **新手不迷路**：87 个专业术语带虚线，点开是一句人话解释；资金、研究点、方法星等游戏概念都有问号说明；六个步骤在进度条下写明。
- **3 分钟快速版**适合游园会：一场就出初步画像，再推荐“最能分清你像谁”的下一场。
- **线下桌游**是同一套内容，卡牌二维码接回线上，另有 3D 打印的物种手办。

### 用户画像合理性（25）

- **只用决定时的行为**：画像看的是证据顺序、选项、理由、计划和快进中的执行，**不使用赚没赚钱**。收益只进收益账和终局分。
- **能力、偏好、习惯分开**：物种只表示偏好；能力用徽章单独记（证据控、说到做到、金融史达人、数据手、规则派、看懂风险）。七个维度逐条标注类型：

  | 维度 | 类型 |
  |---|---|
  | 证据使用 | 能力 / 习惯 |
  | 金融知识与历史 | 能力 |
  | 量化与工具准备度 | 能力 |
  | 决策依据 | 偏好 |
  | 兴趣市场与主题 | 偏好 |
  | 风险姿态 | 偏好 |
  | 逆境反应 | 习惯 |

- **每条判断都有依据和把握**：点开任何一个维度，能看到对应的具体行为；把握表示证据够不够，不是分数高低。证据不足的写进“待确认”，比如样本只有一两场、两个物种并列。
- **正面处理“游戏不等于实盘”**：风险类结论只标“游戏内表现”；开局自评、游戏行为、终局两道现实题三方对照；自评和行为不一致时直接写出来。
- **区分可见信息和后续结果**：盲测和证据只给决定日之前的数据（页面上有数据戳说明）；揭幕才给完整区间。认出事件的玩家可以申报，这一场的收益改按 AI 平均记，物种币只算半枚，避免把“知道结局”当成“判断准”。
- **查过的词也是线索**：玩家点开过哪些术语，会作为“金融知识与历史”的依据。

### 个性化推荐价值（25）

- **12 张任务卡**：假设检验、证据核查、状态判断、读图入门、数据自主探索、风险校准，各分入门和进阶。选哪张由行为决定，比如理由多是“看不懂”的推荐读图入门，多是“消息 / 跟别人”的推荐证据核查，因为等证据而观望的推荐状态判断。
- **每条推荐都写“因为……”**，并列出“暂时不推荐什么、为什么”。
- **当场能做**：终局按推荐类型给一个约 1 分钟的小任务。假设检验是把一条规则放回玩家走过的名场面，按真实日线回放，和玩家自己的结果对比；证据核查是判断三条“流传的说法”真假；读图入门是 30 秒读一张成交量图；数据自主探索是改一行 `panda_data` 参数重跑一个名场面；状态判断是选出自己在等的三个信号；风险校准是对照游戏里和现实里的选择。
- **接到 PandaAI 的下一步**：根据玩家用过的规则牌、主要理由或观望方式，生成一句给 Qube 的策略描述（比如“用 MA5/20/60 多均线趋势过滤回测上证指数 2024 年 9 月到 12 月……”），一键复制并打开 Qube；另附 QuantSkills 技能和 PandaAI 产品链接。
- **快速版的下一场推荐**：在没玩过的名场面里，选两个候选物种做法分歧最大的一场，用来消除不确定。

### Panda Data 应用价值（15）

| 用在哪 | 接口 |
|---|---|
| 上证、沪深 300、创业板指、中证 1000、国证 2000 日线（924、2015、量化踩踏等场） | `get_index_daily` |
| 贵州茅台日线和前复权日线（茅台一场的行情和收益） | `get_stock_daily`、`get_stock_daily_pre` |
| 茅台 PE TTM、PB（数据证据） | `get_factor` |
| 上证指数 PE、PB（数据证据） | `get_index_indicator` |
| 2015 年跌停和停牌家数、924 两市成交额（全市场逐只统计） | `get_stock_daily` |
| 纳指 ETF 513100（2020 熔断一场） | `get_fund_daily` |
| 上海原油 SC 各月合约结算价（原油宝一场） | `get_future_daily` |

- 收益表、快进行情、规则牌回放都按真实日线计算。
- 每张走势图下有数据戳：盲测阶段只写来源和“只显示决定日之前”，揭幕阶段写出标的、代码、接口、字段和完整区间。
- 棋盘上的“数据港口”让玩家读一段 `panda_data` 调用代码并回答问题，答对两次得“数据手”徽章，并进入“量化与工具准备度”的依据。
- Panda Data 没有覆盖的部分使用公开接口，页面上同样标注来源：美股指数、WTI 连续合约、两融余额（交易所口径）。

### 完成度与创新性（10）

- H5 完整可玩：快速版和完整四季版、六个名场面、终局画像、分享图、结构化画像 JSON；自动通关脚本覆盖四条路径（快速版两场和完整版三种打法）。
- 桌游完整可印：棋盘、各类卡牌、委托单、玩家板、规则书、快速入门卡、盒标，3 mm 出血、真二维码；七个物种手办和令牌的 3D 打印文件。
- 创新点：用“怎么做决定”而不是问卷来画像；能力、偏好、习惯分开，每条判断带依据和把握；线上线下同一套内容，扫码互通。

## 差异化演示：同一个画像引擎，五种玩家

评委演示台（`/demo`）里的五位模拟玩家走同样的名场面，结果全部由真实玩家用的同一个画像函数算出：

| 模拟玩家 | 开局自评 | 游戏里像 | 推荐 |
|---|---|---|---|
| 一路追涨：每场先看走势、敢上满仓 | 大象 | 猎豹 · 很确定 | 假设检验 · 入门，加推风险校准 · 入门 |
| 等证据：先看数据，多数时候选等 | 猫头鹰 | 猫头鹰 / 大象 · 待确认 | 状态判断 · 进阶 |
| 跟着消息走 | 猎豹 | 狐獴 · 很确定 | 证据核查 · 入门 |
| 新手看不懂：理由多是“看不懂” | 狐獴 | 猎豹 · 初步 | 读图入门 · 入门 |
| 规则派：用规则牌做决定、读代码 | 狐狸 | 狐狸 · 比较确定（隐藏特质：海狸） | 数据自主探索 · 进阶 |

**改一个关键选择，看结果怎么变**（现场可复现）：

- “等证据”这位玩家，把春 · 924 的决定从“C 等回调再说”改成“A 节后开盘追入”：物种从“猫头鹰 / 大象 · 待确认”变成“大象 · 比较确定”，推荐从“状态判断 · 进阶”变成“假设检验 · 进阶”，给 Qube 的那句话也随之改变。同样先看数据，看完选择等是猫头鹰，看完选择买是大象。
- “一路追涨”这位玩家，把任意一场的理由从“量价”改成“数据”或“消息”：物种仍是猎豹，把握从“很确定”降到“比较确定”。四场一致的证据，一次改动推不翻，只会降低把握。

## 接入 PandaAI 的构想（尚未实现）

- 终局可导出结构化画像（`trading-species/profile@1`）：物种与把握、各维度的等级、依据和把握、待确认、推荐与理由、暂不推荐、查过的术语、玩过的场数。**目前是格式示例，没有接入任何平台账号。**
- 校准顺序：开局自评 → 游戏行为 → 现实题 → 平台研究行为（Qube 回测、因子评估）→ 模拟盘。接入后，平台行为可以继续修正画像里“待确认”的部分。
- Qube 一句话目前通过复制粘贴交接；接入后可以直接带参数打开。

## 标注：哪些是真实的，哪些是示例

| 类别 | 内容 |
|---|---|
| 真实 | 历史事件；行情和估值数据（Panda Data 与标注过的公开接口）；收益结算和规则牌回放结果；Qube、QuantSkills 和 PandaAI 产品链接 |
| 模拟 | 评委演示台的五位玩家；游戏里的两只 AI 对手（按物种规则决策） |
| 示例 | 画像 JSON 的平台对接格式；推荐资源中标“示例”的条目（PandaAI 学习中心的具体课程待选）；当场任务里的核查题和状态信号清单（页面已标“示例”）；数据自主探索任务的代码输出是用同一份 Panda Data 日线预先算好的 |
| 未实现 | PandaAI 账号登录与画像回写；用平台行为修正画像；线上多人对局（多人玩法目前在桌游里） |

## 隐私

- 不需要登录，不收集个人信息。游戏记录只保存在玩家本机浏览器里。
- 分享图只有物种和徽章，不含任何行为记录；现实题答案只留在本机。
- 扫码页面不记录任何信息。演示材料不含个人信息和数据访问密钥。

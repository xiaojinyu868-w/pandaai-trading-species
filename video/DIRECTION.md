# 《交易物种起源》视频方向

## 口径

只讲两件事：好玩（盲盒猜年份、按住拿松手卖、跌停卖不出、借钱、三二一亮单、熔断沙漏）和有用（真实行情、AI 复盘、习惯写成规则去 Qube 回测、任务牌指向真实工具）。不讲理念口号。

## 范围

- 两条片子，拼成一条提交版（约 4 分 30 秒，1920×1080，30 fps，中文，配音 + 字幕）：
  1. **宣传片**（约 1 分 50 秒）：讲整个项目。故事 → 一盒桌游一部手机 → 手机上玩一场 2015 → AI 复盘 → PandaAI 下一步 → 线上线下接回。
  2. **桌游玩法**（约 2 分 40 秒）：只讲线下怎么玩。开盒 → 准备 → 一季 → 名场面六步 → 招牌机制 → 驿站 → 终局 → 单人 → 扫码。
- 平台面：手机 H5（线上真站录屏）+ 印刷桌游（印刷文件导出的真实卡面）。**没有覆盖**：评委演示台以外的后台、桌游的实拍（这一版不拍实物，用印刷文件做桌面动画）。
- 两条也单独导出：宣传片在拼接点切出，桌游片从拼接点开始。

## 产品气质（来源）

- 谁在用：PandaAI 的种子用户，略懂投资的人和小白；投教课堂、展会、朋友聚会。感觉是**好玩、有点老派的纸面游戏**，不是金融终端。
- 设计语言：纸色底 `#f2e6cc`、墨色 `#2a2a1c`、风筝红 `#d4432a`（涨）、叶绿 `#3c7a4e`（跌），硬边投影 `3px 3px 0 墨色`，季节色春 `#6fa463` 夏 `#d4432a` 秋 `#c98a2e` 冬 `#4e8792`（`h5/src/styles.css:1-28`）。
- 字体：标题得意黑 Smiley Sans Oblique（中英文都用它，这是产品和印刷件本身的做法），正文 Noto Sans SC（`h5/src/styles.css:24-25`，印刷件同款）。
- 母题候选：真实走势线一格一格长出来（`arcade/Game.tsx`）；名场面卡的盲测面 / 揭幕面；委托单的勾选、对折、亮单；印章（揭幕页的“节后逃顶”“被强平”）；按住的手指；七个物种立绘。

## 三个方向

| | A 报纸头版 | B 交易大屏 | C 桌面手账 |
|---|---|---|---|
| 底色与光 | 纸白 + 墨线 + 网点 | 黑底 + 发光 K 线 | 深木色桌面 + 实物卡片投影 |
| 字体 | 得意黑粗标题，报头式 | 等宽数字 | 手写感 + 得意黑 |
| 母题 | 走势线、印章、头版标题 | 行情跳动、数字滚动 | 卡牌、骰子、委托单 |
| 镜头 | 平面排版编辑，推拉 | 3D 环绕屏幕 | 俯拍桌面平移 |
| 转场 | 走势线擦除、印章砸下 | 数字故障 | 卡牌翻面、纸张滑入 |
| 节奏 | 预告片开头，后面从容 | 紧凑 | 安静讲解 |

**选择：宣传片用 A，桌游片用 C。**宣传片要像产品本身（H5 就是纸面 + 墨线 + 得意黑），评委一眼能认出是同一个东西；B 的黑底发光是金融终端的语气，和“投资者教育游戏、给小白”的定位相反。桌游片讲实物玩法，用 C 的桌面俯拍，让观众像坐在桌边；和宣传片在底色、镜头、转场三个轴上都不同，两条连着看不会腻。

## 本片专属手法

1. **因为游戏的核心是“真实走势一格一格长出来，看不到下一格”，所以转场用一条真实走势线擦过画面**：线走到哪，新画面露到哪（宣传片从历史名场面到片名、从手机到揭幕）。线用 Panda Data 的真实日线（2015 上证指数）。
2. **因为委托单要“勾、对折、三二一亮单”，揭幕页有印章，所以关键结论用印章砸下**（“不是韭菜”“你会怎么选”“当场重算”），墨色略微晕开，配一声闷响。
3. **因为名场面卡有盲测面和揭幕面，所以章节转换用卡牌翻面**：桌游片里场景牌、证据牌、揭幕牌都真的翻过来，背面是印刷件的真实背面。
4. **因为手机上只有一个手势“按着 = 拿着”，所以手机镜头里叠一个手指圈**：按着时圈在，松开时圈消失；声音上按着有一层低频持续音，松开就断。
5. **因为结果是“七个物种”，所以物种立绘像报纸头版的人物栏一样排开**，被点到的那一只放大、其他压暗。

不用：回弹缓动、彩虹渐变、黑底霓虹、无意义的晃动、所有元素同一种淡入。

## 画面规范

- 1920×1080，30 fps。重要内容避开底部 140 px，那里留给字幕条。
- 宣传片底色纸色 `#f2e6cc` + 颗粒；桌游片桌面 `#3a2f24` 木色渐变 + 暗角，卡片带 `0 18px 40px rgba(0,0,0,.45)` 投影。
- 字号：主标题中文 104 px 得意黑；次标题 64 px；说明 40 px Noto 500；英文小标 26 px 得意黑字距 .18em；数据戳 24 px。字幕 38 px Noto 700，墨色字在纸色半透明条上（桌游片为白字黑条）。
- 手机：390 px 宽的页面按 1.2 倍上镜（屏幕 468×1013 px，外框圆角 56 px），正文约 19–20 px；关键时刻推近到 1.6–1.8 倍，让按钮和印章文字 ≥ 22 px。**例外说明**：线上小游戏有自己的计时器、状态和 framer-motion 动画，无法逐帧 seek，所以手机画面用机器人在线上真站用真实手势玩的录屏（`tools/rec_phone.py`，2 倍像素），逐帧贴进片子里；这仍是产品本身的画面，不是重画的。
- 动效语法：入场 0.35–0.6 s，`power3.out` / `expo.out`；印章 0.18 s 砸下 + 0.4 s 墨晕；卡牌翻面 0.6 s `power2.inOut`；镜头推拉 `sine.inOut`。
